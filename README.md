# 関東燃料 業務日報（社内専用）

gamba の代わりに使う、関東燃料専用の業務日報アプリです。スマホのブラウザで使え、ホーム画面に追加すればアプリのように起動できます。

## できること

| 機能 | 内容 |
|---|---|
| 日報投稿 | 今日やるべきこと／今日やったこと・結果／よかったこと・改善点→改善策／共有・連絡事項／相談したいこと／翌出社日への決意・目標／翌出社日のスケジュール、出社・退社・休憩時刻、写真（最大10枚・自動縮小） |
| **前日の予定を自動で引き継ぎ** | 前回の「翌出社日のスケジュール」が、次の日報の「今日やるべきこと」に最初から入ります。出社・退社・休憩時刻も前回の値を引き継ぎます |
| **書きかけの自動保存** | 入力途中で画面を閉じても、同じ日付で開き直すと復元されます |
| KPI | 日報と一緒に本日の件数・金額・内容を入力 → 月目標・月累計・達成率・金額累計を自動計算（gamba のように KPI を別投稿する必要はありません） |
| KPI 集計 | 月ごとに全員の実績／目標／達成率を一覧表示。CSV（Excel 対応）で出力できます |
| タイムライン | 全員の日報を新しい順に表示。投稿者で絞り込み、キーワード検索、未読だけを表示 |
| 開封・未読 | 画面に表示された日報は自動で「開封」になり、誰が開封したかアイコンで表示 |
| いいね！・スタンプ・コメント | 反応があると投稿者に通知されます |
| 管理（管理者のみ） | 会社ロゴ・会社名の設定、社員の追加・権限・利用停止・パスワード再設定、KPI 項目の追加・名前変更・並び順・非表示 |
| 日報 CSV 出力 | 月単位で全員分の日報を CSV に出力（バックアップ・集計用） |

KPI 項目の初期値は「提案／受注 × リフォーム・給湯器・エコキュート・雑工事」です。LPガスや灯油など、管理画面から自由に追加できます。

## 動かし方

必要なもの: **Node.js 22.5 以上**（追加のパッケージのインストールは不要です）

```bash
npm start
```

初めて起動すると、管理者アカウント（ログインID `admin`）のパスワードが画面に表示されます。
`ADMIN_PASSWORD=好きなパスワード npm start` のように指定することもできます。

1. ブラウザで `http://サーバーのIPアドレス:3000` を開き、admin でログイン
2. 「メニュー」→「社員・KPI項目の管理」で社員を登録（ログインIDと初期パスワードを本人に伝える）
3. 管理者アカウントの名前やパスワードは、管理画面・メニューから変更してください
4. 各自スマホでログインし、ブラウザのメニューから「ホーム画面に追加」

### 設定（環境変数）

| 変数 | 既定値 | 内容 |
|---|---|---|
| `PORT` | `3000` | 待ち受けポート |
| `DATA_DIR` | `./data` | データベースと写真の保存先 |
| `ADMIN_PASSWORD` | ランダム | 初回起動時の管理者パスワード |
| `COOKIE_SECURE` | なし | `1` にすると HTTPS 専用のログイン Cookie にします |
| `TZ` | `Asia/Tokyo` | タイムゾーン |

### 社外（外回り中）からも使う場合

社内ネットワークだけで使う場合は、社内のPCやNASで起動すれば十分です。
外出先のスマホから使う場合は、HTTPS 対応のサーバー（クラウドの VPS など）に置き、
`COOKIE_SECURE=1` を設定してください。どちらの方法にするかは、ご相談のうえで決めましょう。

### Render（クラウド）に置く場合

`render.yaml` に設定をまとめてあります。

1. https://render.com に GitHub アカウントでログイン
2. 「New」→「Blueprint」→ このリポジトリを選び、「Apply」
3. 支払い情報を登録（Starter プラン ＋ 1GB ディスク）
4. できあがった `https://〜.onrender.com` を開き、`admin` でログイン
   （パスワードは Render の「Environment」→ `ADMIN_PASSWORD` に表示されます）

| 変数 | 内容 |
|---|---|
| `TRUST_PROXY` | `1` にすると、ログイン失敗の回数制限を中継サーバーが付けた接続元ごとに数えます（Render などで使用） |

### バックアップ

`data/` フォルダ（`nippo.db` と `uploads/`）をまるごとコピーすれば保存できます。
あわせて KPI 画面から月ごとの CSV を出力しておくと安心です。

## 開発

```bash
npm test   # API の自動テスト
```

- `server.js` … サーバー（API・認証・ファイル配信）
- `lib/db.js` … データベースの定義（SQLite）
- `public/` … 画面（HTML / CSS / JavaScript）
